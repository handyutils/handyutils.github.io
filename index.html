The collection

dsopt

Rust

Finds node_modules and Rust target/ directories, shows what they cost, and reclaims the space — with a confirmation before anything is deleted.

cargo install dsopt
Website Repo crates.io

sctxx

Rust

Session ConTeXt eXtractor: turns a coding-agent transcript (Claude Code, Codex CLI, Pi) into a compact, verified, provenance-linked handoff any other agent can continue from.

cargo install sctxx
Repo crates.io

agentman

Rust

A colourful local TUI for managing coding-agent sessions across the agents installed on your machine.

cargo install agentman
Repo crates.io

cbmman

Rust

Interactive manager for codebase-memory-mcp: index, query, and monitor codebase knowledge graphs from the terminal.

cargo install cbmman
Repo crates.io

nvmman

Rust

Maintains nvm Node.js installations: installs and verifies the latest platform LTS, migrates global npm packages, and keeps a consolidated registry so any version can be restored.

cargo install nvmman
Repo crates.io

mcpmanrs

Rust

A Rust TUI for managing MCP servers on macOS, Linux, and other Unix systems — add, inspect, and toggle servers without hand-editing config files.

cargo install mcpmanrs
Repo crates.io

justtuit

TypeScript

Just TUI it! — a TUI for TUI tools. Browse 672 terminal applications across 13 categories, and launch the one you need.

Installing

Rust tools come from crates.io; the TypeScript one comes from npm.

shell
# Rust tools — installs a single static binary into ~/.cargo/bin
cargo install dsopt
cargo install sctxx
cargo install agentman
cargo install cbmman
cargo install nvmman
cargo install mcpmanrs

# TypeScript tool
npm i -g justtuit

Need Rust first? Install it from rustup.rs. Every Rust tool here supports --update where built in, or cargo install <name> --force to upgrade.
